# คู่มือเลือกแผนภาพ แบบฝึกหัด และแบบทดสอบให้เหมาะกับเนื้อหา

## เลือกแผนภาพตามสิ่งที่ต้องการสื่อ

| ต้องการสื่อ | ใช้ | Mermaid |
|---|---|---|
| ขั้นตอน กระบวนการ การตัดสินใจ | Flowchart | `flowchart TD` |
| เหตุ → ผล, วงจรป้อนกลับ | Flowchart แบบวง / causal loop | `flowchart LR` |
| โครงสร้าง ลำดับชั้น การจำแนกประเภท | Mind map / tree | `mindmap` หรือ `flowchart TD` |
| ลำดับเวลา วิวัฒนาการของแนวคิด | Timeline | `timeline` |
| ปฏิสัมพันธ์ระหว่างผู้เกี่ยวข้อง | Sequence | `sequenceDiagram` |
| สถานะที่เปลี่ยนไป | State diagram | `stateDiagram-v2` |
| เปรียบเทียบ 2 มิติ (เช่น เร่งด่วน/สำคัญ) | Quadrant | `quadrantChart` |
| เปรียบเทียบหลายแนวคิดหลายมิติ | ตาราง HTML | — |
| สัดส่วน | Pie | `pie` |

กฎ: ข้อความในโหนดสั้น (≤ 6 คำ) ใส่เครื่องหมายคำพูดรอบข้อความภาษาไทยหรือที่มีวงเล็บ เช่น `A["ต้นทุนจม (sunk cost)"]` ใต้แผนภาพเขียนคำอธิบาย 1–2 ประโยคว่าควรอ่านภาพอย่างไร

## เลือกชนิดกิจกรรมตามธรรมชาติเนื้อหา

| ธรรมชาติเนื้อหา | กิจกรรมที่ได้ผล |
|---|---|
| นิยาม ศัพท์ ข้อเท็จจริง | จับคู่, เติมคำ, flashcard, ปรนัยระดับจำ |
| แนวคิด/หลักการเชิงนามธรรม | "ข้อใดเป็น/ไม่เป็นตัวอย่างของ...", อธิบายด้วยคำของตัวเอง, อุปมา |
| กระบวนการ/ขั้นตอน | เรียงลำดับ, หาขั้นตอนที่ผิด, ทำตาม worked example แล้วทำเอง (faded example) |
| สูตร/การคำนวณ | โจทย์ตัวเลขไล่ระดับ, หาจุดผิดในวิธีทำ, ประมาณค่าก่อนคำนวณ |
| ทฤษฎีที่ใช้อธิบายพฤติกรรม/ปรากฏการณ์ | กรณีศึกษา "อธิบายเหตุการณ์นี้ด้วยทฤษฎี", ทำนายผล |
| แนวคิดที่คล้ายกัน | จำแนกสถานการณ์ลงกลุ่ม, ตารางเปรียบเทียบเติมช่อง |
| หลักการตัดสินใจ/เชิงปฏิบัติ | สถานการณ์จำลอง (scenario) มีทางเลือกและผลที่ตามมา |
| ข้อถกเถียง/ทฤษฎีเชิงวิพากษ์ | ประเมินข้อโต้แย้ง, ระบุข้อจำกัด, เขียนจุดยืนพร้อมเหตุผล |

## ระดับ Bloom → รูปแบบคำถาม

| ระดับ | คำกริยา | ตัวอย่างโจทย์ |
|---|---|---|
| จำ | บอก ระบุ | "...หมายถึงข้อใด" |
| เข้าใจ | อธิบาย ยกตัวอย่าง | "ข้อใดเป็นตัวอย่างของ..." |
| ประยุกต์ | ใช้ แก้ปัญหา | "บริษัท A เจอปัญหา... ควรใช้หลักใด อย่างไร" |
| วิเคราะห์ | แยกแยะ เปรียบเทียบ หาสาเหตุ | "สถานการณ์นี้ต่างจาก...อย่างไร เพราะอะไร" |
| ประเมิน | ตัดสิน วิจารณ์ | "แนวทางนี้เหมาะสมหรือไม่ ภายใต้เงื่อนไขใด" |
| สร้างสรรค์ | ออกแบบ เสนอ | "ออกแบบ...โดยใช้หลัก..." |

สัดส่วนแนะนำสำหรับแบบทดสอบรวม: จำ/เข้าใจ ~30%, ประยุกต์ ~30%, วิเคราะห์/ประเมิน ~30%, สร้างสรรค์ (ปลายเปิด) ~10%

## หลักเขียนข้อสอบปรนัย
- คำถามชัด ถามเรื่องเดียว หลีกเลี่ยงปฏิเสธซ้อน
- ตัวเลือกยาวใกล้เคียงกัน ไม่มีตัวเลือก "ถูกทุกข้อ/ผิดทุกข้อ" พร่ำเพรื่อ
- ตัวลวงแต่ละตัวสะท้อนความเข้าใจผิดที่มีจริง เขียน feedback เฉพาะตัวลวงนั้น
- กระจายตำแหน่งคำตอบที่ถูก
