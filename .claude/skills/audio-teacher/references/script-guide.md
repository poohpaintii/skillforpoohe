# คู่มือเขียนสคริปต์สอนด้วยเสียง

## รูปแบบไฟล์ (ที่ make_audio.py อ่าน)

- ย่อหน้าคั่นด้วยบรรทัดว่าง — แต่ละย่อหน้าจะมีช่วงหยุดสั้น ๆ ต่อท้ายอัตโนมัติ
- `[pause]` = หยุด 1.5 วินาที, `[pause 3]` = หยุด 3 วินาที (อยู่บรรทัดเดียวโดด ๆ)
- บรรทัดขึ้นต้นด้วย `#` = หัวข้อ/โน้ต ไม่ถูกอ่านออกเสียง (ใช้แบ่งส่วนให้คนอ่านสคริปต์)
- ย่อหน้าละ 2–4 ประโยค ประโยคสั้น เว้นวรรคระหว่างวลีตามธรรมชาติภาษาไทย (ช่วยให้ TTS หายใจถูกจังหวะ)

## โครงหนึ่งตอน

```
# [1] เปิดตอน (~30 วินาที)
ทักทาย บอกว่าตอนนี้ตอนที่เท่าไหร่ เรื่องอะไร และฟังจบแล้วจะทำอะไรได้
ถ้าไม่ใช่ตอนแรก ทวนตอนที่แล้ว 2–3 ประโยค

# [2] ดึงความสนใจ (~1 นาที)
เรื่องเล่าสั้น/สถานการณ์/คำถามที่ทำให้อยากรู้

# [3] แผนที่ของตอน
"วันนี้เราจะคุยกัน 3 เรื่อง เรื่องแรก... เรื่องที่สอง... และสุดท้าย..."

# [4] เนื้อหา — ทำซ้ำรอบนี้ต่อแต่ละประเด็น
- บอกว่ากำลังเข้าประเด็นที่เท่าไหร่
- อธิบายแบบง่ายก่อน แล้วค่อยเพิ่มความละเอียด
- อุปมา/ตัวอย่างใกล้ตัว 1–2 ตัวอย่าง
- จุดที่คนมักเข้าใจผิด
- สรุปประเด็นนี้หนึ่งประโยค

# [5] ชวนคิด (กลางตอน และ/หรือ ก่อนสรุป)
ตั้งคำถาม → [pause 3] → เฉลยพร้อมเหตุผล

# [6] สรุปท้ายตอน
ทวนแนวคิดหลักเป็นข้อ ๆ ด้วยคำพูดใหม่ (ไม่ใช่ประโยคเดิม)
"ถ้าจำได้อย่างเดียวจากตอนนี้ ขอให้จำว่า..."

# [7] ปิดตอน
การบ้านเล็ก ๆ ให้ลองสังเกตในชีวิตจริง + บอกว่าตอนหน้าจะเรียนอะไร
```

## สำนวนครูที่ใช้ได้ (หมุนเวียน อย่าใช้ซ้ำจนน่าเบื่อ)

- เปิดประเด็น: "เอาล่ะ มาถึงเรื่องสำคัญกันแล้ว", "ทีนี้ คำถามคือ..."
- อธิบายซ้ำ: "พูดอีกแบบหนึ่งก็คือ...", "ถ้าให้เปรียบเทียบง่าย ๆ..."
- ยกตัวอย่าง: "ลองนึกภาพนะ...", "สมมติว่าคุณ...", "เคยไหม ที่..."
- เน้น: "ตรงนี้สำคัญมาก", "จุดนี้หลายคนพลาด"
- ชวนคิด: "ลองหยุดคิดสักครู่ก่อนฟังต่อนะ..."
- เชื่อม: "ซึ่งพาเราไปสู่เรื่องต่อไป..."

## กฎเขียนให้ TTS อ่านถูกและผู้ฟังเข้าใจ

| แทนที่จะเขียน | ให้เขียน |
|---|---|
| ตัวเลขยาว / ปี: 2,500,000 / พ.ศ. 2567 | "สองล้านห้าแสน" / "ปีสองพันห้าร้อยหกสิบเจ็ด" (ตัวเลขสั้น ๆ เขียนเป็นเลขได้) |
| สูตร a² + b² = c² | "a กำลังสอง บวก b กำลังสอง เท่ากับ c กำลังสอง" แล้วอธิบายความหมายเป็นภาษาคน |
| ตัวย่อ: ฯลฯ, เช่น ศ., GDP | "และอื่น ๆ", "ศาสตราจารย์", "จีดีพี หรือผลิตภัณฑ์มวลรวมในประเทศ" |
| สัญลักษณ์ %, →, &, / | "เปอร์เซ็นต์", "นำไปสู่", "และ", "หรือ" |
| ตาราง | เล่าเป็นการเปรียบเทียบทีละประเด็น: "ในด้าน... แบบแรก... ส่วนแบบที่สอง..." |
| แผนภาพ | "ลองนึกภาพ..." บรรยายตำแหน่งและความสัมพันธ์ทีละส่วน |
| วงเล็บอธิบาย (...) | แยกเป็นประโยคใหม่ "หรือที่ภาษาอังกฤษเรียกว่า..." |
| ศัพท์อังกฤษยาก | เขียนทับศัพท์ไทยตามที่คนไทยออกเสียง หรือสะกดอังกฤษคำสั้น ๆ |
| ไม้ยมก ๆ | ใช้ได้ แต่เว้นวรรคหน้า-หลังให้ถูก |
| bullet / ตัวหนา / markdown | ห้ามใช้ในส่วนที่อ่านออกเสียง |

## ตัวอย่างสั้น

```
# เปิดตอน
สวัสดีค่ะ ยินดีต้อนรับสู่ตอนที่สองนะคะ ตอนที่แล้วเราคุยกันเรื่องต้นทุนค่าเสียโอกาส วันนี้เราจะต่อยอดไปอีกเรื่องหนึ่ง ที่ทุกคนเคยเจอแน่นอน แต่อาจไม่รู้ว่ามันมีชื่อเรียก นั่นคือ ต้นทุนจม

# ดึงความสนใจ
ลองนึกภาพนะคะ คุณซื้อตั๋วหนังราคาสามร้อยบาท ดูไปได้ยี่สิบนาที แล้วพบว่าหนังน่าเบื่อมาก คำถามคือ คุณจะนั่งดูต่อจนจบ หรือลุกออกมา

[pause 3]

ถ้าคุณคิดว่า เสียดายเงิน ต้องดูให้คุ้ม ไม่ต้องรู้สึกผิดนะคะ เพราะคนส่วนใหญ่ก็คิดแบบนี้ และนี่แหละ คือสิ่งที่เราจะมาทำความเข้าใจกันวันนี้
```
